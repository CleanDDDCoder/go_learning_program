# Package Design Principles

This lesson covers the fundamental principles of effective package design in Go.

## Learning Objectives

- Understand the importance of package organization
- Learn how to split code into logical units
- Apply the principle of low coupling and high cohesion

## Exercise

Create a package called `calculator` that provides basic arithmetic operations. The package should:
1. Have a clear, focused purpose
2. Export only necessary types and functions
3. Use meaningful names

## Hints

- Start with a single file and refactor as needed
- Consider what the user of your package needs to see
- Keep related functionality together
